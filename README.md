# 📊 Талдау көмекшісі — мұғалімге көмекші

Мектептің Excel-есептерін талдайтын Streamlit веб-қосымшасы.

## Не істейді

1. **Батырма арқылы Excel файлды жүктейсіз** (бірнеше файлды бірден жүктеуге болады).
2. Файл түрін өзі анықтайды:
   - **сыныптың тоқсандық ведомосі** (Аты-жөні × пәндер, орта балл, үздіктер, екпінділер, резерв);
   - **БЖБ / ТЖБ талдауы** (төмен / орташа / жоғары деңгейлер);
   - **параллельдер бойынша үлгерім** (оқу озаты, екпінділер, білім сапасы);
   - **кез келген ұқсас есеп** (мониторинг, срез т.б.) — әмбебап режимде.
3. Есептейді және тексереді: орта балл, білім сапасы, үлгерім, санаттар тізімі, резерв, кестедегі қателер.
4. **ChatGPT үшін промптты өзі дайындайды** — барлық деректер мен есептеулер ішінде.
5. **ChatGPT талдауын жасайды** — екі тәсілмен:
   - 💬 **тегін**: промптты көшіріп chatgpt.com-ға қоясыз, жауабын қайта қосымшаға қоясыз;
   - 🤖 **автоматты**: OpenAI API кілті болса, қосымша ChatGPT-ке өзі жібереді.
6. **Толық есепті Word (.docx) және Excel (.xlsx) файлына сақтайды** — кестелер, автоматты талдау және ChatGPT талдауы.
7. Бірнеше файл жүктелсе — **жиынтық салыстыру** (тоқсандар динамикасы, сыныптарды салыстыру).

## GitHub-қа сақтау және Streamlit-те веб-парақ ретінде ашу

1. GitHub-та жаңа репозиторий жасаңыз (мысалы, `talday-komekshisi`).
2. Осы папкадағы барлық файлдарды жүктеңіз: `app.py`, `requirements.txt`, `README.md`, `.gitignore` және `.streamlit` папкасы.
   (GitHub сайтында: **Add file → Upload files** → файлдарды сүйреп әкеліңіз → **Commit changes**.)
3. [share.streamlit.io](https://share.streamlit.io) сайтына GitHub арқылы кіріңіз.
4. **Create app** → репозиторийді, `main` тармағын және `app.py` файлын таңдаңыз → **Deploy**.
5. Бірнеше минуттан кейін қосымша `https://….streamlit.app` сілтемесімен ашылады — оны әріптестерге жіберуге болады.

### Кілттер (міндетті емес)

Тегін режим үшін кілт керек емес. Автоматты режим үшін Streamlit → **App settings → Secrets** бөліміне қосыңыз:

```toml
OPENAI_API_KEY = "sk-..."              # ChatGPT (platform.openai.com → API keys)
ANTHROPIC_API_KEY = "sk-ant-api03-..." # Claude (console.anthropic.com)
```

Сақтағаннан кейін **Reboot app** басыңыз. API ақылы: ChatGPT Plus жазылымы API-ге ақша бермейді, балансты platform.openai.com → Billing арқылы толтыру керек.

⚠️ Кілті бар `.streamlit/secrets.toml` файлын GitHub-қа ешқашан жүктемеңіз — ол `.gitignore`-да тұр.

## Өз компьютерде іске қосу

```bash
pip install -r requirements.txt
streamlit run app.py
```

Браузерде http://localhost:8501 ашылады.

## Ескертпелер

- Ескі `.xls` форматын алдымен Excel-де `.xlsx` ретінде қайта сақтаңыз.
- Тоқсандарды салыстыру үшін файлдарды ретімен жүктеп, түсінікті атаңыз: `1 тоқсан.xlsx`, `2 тоқсан.xlsx`.
- «Есептелінді» сияқты бағаланбайтын пәндер (дене шынықтыру) орташа балл мен сапаға кірмейді.
